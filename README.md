# 학교 픽셀 디자인 시안

완료: classroom-front-v1.png / classroom-rear-v1.png / school-exterior-v1.png / student-characters-v1.png. 사용자 승인 후 ChatGPT 내장 이미지 생성으로4장 제작, 원본을 프로젝트 폴더에 복사 보존. 프롬프트 전문 prompts-v1.json. 학생은 가상의6명/앞뒤 모습이며 실물 얼굴 재현 아님. 복도는 참조 사진 미첨부라 미생성.

검토: 교실 앞면/뒤면의 책걸상·창문·수납장, 뒤쪽 오른편 보관함/공기청정기, 외관의 왼쪽 별관/오른쪽 본관 반영. 전후면 생성은 동일3D 공간의 정확한 재구성이 아니므로 가구 수/창문/시점의 완전 일치는 보장하지 않음. 배경은 세밀한 픽셀풍 원근 장면으로 ZEP의 단순한 타일맵보다 상세함. 캐릭터는 디자인 시트이며 투명 배경/프레임 정렬/걷기 애니메이션은 아직 없음. 시안 승인 전 반복 생성/게임 적용 안 함.

사용자 요청: 실제 교실/학교 외관을 참고한 ZEP 느낌 픽셀 배경과 가상의2학년 학생 캐릭터.
첨부3장: 교실 앞쪽/학교 외관/교실 뒤쪽. 복도 사진은 없음. 오른쪽 태블릿 보관함/공기순환기는 사용자 설명 반영.
Higgsfield: 참조3장 업로드 성공, 첫 생성은 Basic 이상 필요 오류로 미제출. 계정 조회 free/10credits. 사용자 동의로 ChatGPT 내장 이미지 생성으로 전환. 결과는 시점/스타일 선택용 시안으로, 즉시 완성된 타일맵·애니메이션 스프라이트라고 간주하지 않는다. 게임 코드는 변경하지 않는다.
